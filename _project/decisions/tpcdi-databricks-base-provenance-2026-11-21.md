# TPC-DI based on databricks-tpc-di: owner decisions and sources, 2026-11-21

## Status

Recorded. This file is the public record of how BenchBox treats the licence of shannon-barrow/databricks-tpc-di, of the decision to ship the TPC-DI tools, and of every owner decision of 2026-11-21 that shaped the TPC-DI rework. It adds no decision of its own: the quoted text below is the owner's, verbatim, and the sections that follow it only name what the repository does because of it.

## What the repository does because of these decisions

- The licence of shannon-barrow/databricks-tpc-di is treated as MIT. The project has no LICENSE file; the treatment rests on the owner's instruction quoted above. `_sources/tpc-di/databricks-tpc-di/LICENSE` carries the standard MIT text with the owner's copyright line and `_sources/tpc-di/databricks-tpc-di/PROVENANCE.md` records the repository, the commit, the paths BenchBox takes and the paths it never takes.
- `_sources/tpc-di/djouallah-tpcdi/LICENSE` carries the MIT notice of the DuckDB implementation used for comparison, pinned to the commit recorded in `PROVENANCE.md` there, for any text later taken from it.
- `COPYRIGHT.md` names both projects as third-party sources and its digest pin in `quality/comment-cleanup-scope.json` is updated with it.
- `tests/unit/core/tpcdi/test_provenance_guard.py` fails when a file recorded in `_sources/tpc-di/databricks-tpc-di/FORBIDDEN_HASHES.json` is in the tree outside the tools directory, when a DIGen, PDGF, dictionary or tools-zip file is anywhere but `benchbox/_binaries/tpc-di/tools/`, and when a `.sql` file under `benchbox/core/tpcdi/etl/` is not listed in `benchbox/core/tpcdi/etl/PROVENANCE.json`.
- The hash list also records the SHA-256 of the four files under the project's `Appendix_v1.1.0/` directory. They are not forbidden; they let the shipped audit, validation and visibility SQL be compared with the project's copies without a clone.
- The appendix SQL is not added by this change. The sourcing of the shared copy is settled by the decision quoted above.
